# Bastidores

Material de trabalho das missões que **não** vai para o site (fica fora de `public/`):

- `imagens-originais/` — imagens em resolução e formato originais (PNG/JPG). O site usa as versões otimizadas em `public/campaigns/<missão>/imagens/`.
- `roteirizacao/`, `versoes-antigas/`, `backups/` — roteiros, rascunhos e versões anteriores.

Nada aqui é apagado sem combinar antes, mesmo que não seja usado no site.

> O repositório no GitHub é público: estes arquivos não aparecem no site, mas podem ser lidos no GitHub.
