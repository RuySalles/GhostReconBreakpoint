## 📖 GLOSSÁRIO TÁTICO DE CAMPO

Para garantir a fluidez das operações e conformidade com as diretrizes do Comando Overlord, todos os operadores devem dominar a terminologia padrão:

* **OPORD (Operation Order):** Ordem de Operações detalhada contendo o planejamento estratégico completo.
* **ROE (Rules of Engagement):** Regras de Engajamento que ditam o nível de letalidade e o uso de furtividade permitidos na zona de infiltração.
* **SITREP (Situation Report):** Relatório de Situação resumindo os parâmetros cruciais e riscos ambientais da missão.
* **VFR (Visual Flight Rules):** Regras de Voo Visual utilizadas para exfiltrações de emergência sob o teto de restrições do espaço aéreo.
